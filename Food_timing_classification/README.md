# Food Delivery Classification

## Project Overview
This project classifies deliveries as fast or delayed using customer, restaurant, weather, and traffic features. It compares K-Nearest Neighbors, Naive Bayes, and Decision Tree classifiers with cross-validation and ROC analysis.

## Technologies Used
Python, pandas, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Keep `Food_Delivery_Time_Prediction.csv` beside the notebook.
2. Launch `main.ipynb` in Jupyter.
3. Run all cells to reproduce preprocessing, model comparison, and evaluation plots.
