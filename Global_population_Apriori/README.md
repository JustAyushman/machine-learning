# Global Pollution Analysis with Apriori

## Project Overview
This project discovers associations in global pollution records using the Apriori algorithm. It preprocesses pollution indices and derives frequent itemsets and rules to highlight relationships among environmental factors.

## Technologies Used
Python, pandas, mlxtend (Apriori, association rules), scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Keep `Global_Pollution_Analysis.csv` in the project directory.
2. Open `main.ipynb` in Jupyter and run the cells to generate itemsets and rules.
3. Refer to `Result.ipynb` for the interpreted rule set.
