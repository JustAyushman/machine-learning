# Global Pollution Regression

## Project Overview
This project models the link between pollution levels and recoverable energy. It prepares air, water, and soil indicators and builds regression-type models to support pollution reduction and energy conversion planning.

## Technologies Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Keep `Global_Pollution_Analysis.csv` in the same directory.
2. Launch `main.ipynb` in Jupyter.
3. Execute the notebook top to bottom to reproduce preprocessing and model assessment.
