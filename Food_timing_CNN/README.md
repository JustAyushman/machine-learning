# Food Timing CNN and Baseline Comparison

## Project Overview
This project predicts delivery status with a dense neural network and contrasts it against a logistic regression baseline. It covers feature engineering from location data, model tuning, and assessment using accuracy, F1, confusion matrix, and ROC curves.

## Technologies Used
Python, pandas, TensorFlow / Keras, Scikeras, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Place `Food_Delivery_Time_Prediction.csv` in the same folder.
2. Open `main.ipynb` in Jupyter.
3. Execute the cells in sequence to train the network, tune parameters, and view results.
