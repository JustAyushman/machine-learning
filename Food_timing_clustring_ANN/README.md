# Food Timing Clustering and ANN

## Project Overview
This project combines unsupervised clustering with a neural network for delivery performance analysis. It derives distance and rush-hour features, explores delivery patterns with clustering and PCA, and trains an MLP to predict delivery status.

## Technologies Used
Python, pandas, scikit-learn (KMeans, DBSCAN, PCA), TensorFlow / Keras, Matplotlib, Seaborn.

## Execution / Usage
1. Ensure `Food_Delivery_Time_Prediction.csv` is present in the directory.
2. Open `main.ipynb` in Jupyter.
3. Run the notebook end to end for clustering visualizations and ANN training.
