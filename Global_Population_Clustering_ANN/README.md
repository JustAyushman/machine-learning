# Global Pollution Clustering and ANN Regression

## Project Overview
This project studies global pollution patterns through clustering and neural network regression. After preprocessing and exploratory review, it groups observations and predicts energy recovery potential, benchmarking the network against linear regression.

## Technologies Used
Python, pandas, scikit-learn (KMeans, GridSearchCV), TensorFlow / Keras, Scikeras, Matplotlib, Seaborn.

## Execution / Usage
1. Install dependencies with `pip install -r requirements.txt`.
2. Ensure `Global_Pollution_Analysis.csv` is in the folder.
3. Open `main.ipynb` in Jupyter and run the cells sequentially; supplementary context is in `task.pdf` and `report.pdf`.
