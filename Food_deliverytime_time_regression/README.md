# Food Delivery Time Regression

## Project Overview
This project estimates food delivery duration from order, location, weather, and traffic attributes. It includes data cleaning, distance computation, encoding, and training of linear and logistic models with standard performance evaluation.

## Technologies Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Place `Food_Delivery_Time_Prediction.csv` in the project folder.
2. Open `main.ipynb` in Jupyter.
3. Execute the cells sequentially to preprocess the data and train the models.
