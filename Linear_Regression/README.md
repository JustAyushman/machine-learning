# Walmart Sales Linear Regression

## Project Overview
This project forecasts weekly Walmart sales from store, economic, and calendar features. It includes distribution checks, date-based feature construction, outlier treatment, and evaluation with MAE, RMSE, R2, and adjusted R2.

## Technologies Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Place `Walmart_Sales.csv` beside the notebook.
2. Open `Linear_Regression.ipynb` in Jupyter.
3. Run the cells in order to generate features, fit the model, and review metrics.
