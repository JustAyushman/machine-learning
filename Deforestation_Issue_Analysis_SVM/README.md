# Deforestation Issue Analysis with SVM

## Project Overview
This project predicts tree cover loss percentage from socioeconomic and environmental indicators. It covers data preparation, SVR model training with hyperparameter tuning, and interpretation of key drivers such as agriculture expansion, policy strictness, and illegal lumbering.

## Technologies Used
Python, pandas, NumPy, scikit-learn (SVR, GridSearchCV, permutation importance), Matplotlib, Seaborn.

## Execution / Usage
1. Place `deforestation_dataset.csv` alongside the notebooks.
2. Open `main.ipynb` in Jupyter and run the cells sequentially to train and evaluate the model.
3. See `result.ipynb` for the summarized findings and recommendations.
