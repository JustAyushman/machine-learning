# Global Pollution Classification

## Project Overview
This project assigns countries to low, medium, or high pollution severity groups based on pollution, energy, and environmental variables. It evaluates Naive Bayes, K-Nearest Neighbors, and Decision Tree models with appropriate validation.

## Technologies Used
Python, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Execution / Usage
1. Place `Global_Pollution_Analysis.csv` alongside the notebook.
2. Open `main.ipynb` in Jupyter.
3. Run all cells to reproduce data preparation, classifier training, and evaluation charts.
