# Exploratory Data Analysis and Preprocessing

## Project Overview
This project demonstrates exploratory analysis and cleaning on the Titanic dataset. It examines distributions, missing values, duplicates, outliers, and correlations, then applies encoding and feature preparation for downstream modeling.

## Technologies Used
Python, pandas, NumPy, Seaborn, Matplotlib, scikit-learn, SciPy.

## Execution / Usage
1. Ensure internet access for loading the Seaborn Titanic dataset, or provide a local copy.
2. Open `eda_and_preprocessing.ipynb` in Jupyter.
3. Run the cells in order to reproduce the cleaning and visualization steps.
